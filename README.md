## About This Project
This project is a Node.js web application built for security testing.
It demonstrates common web vulnerabilities and their fixes.

---

## Week 1: Vulnerabilities Found
| Vulnerability | Location | Severity |
|---|---|---|
| XSS (Cross-Site Scripting) | Search Box | HIGH |
| SQL Injection | Login Form | CRITICAL |
| Weak Password | Login Page | HIGH |
| No Input Validation | All Forms | HIGH |
| Plaintext Passwords | Database | CRITICAL |

---

## Week 2: Security Fixes Applied
| Package | Purpose |
|---|---|
| bcryptjs | Password hashing |
| jsonwebtoken | JWT Authentication |
| helmet | Secure HTTP Headers |
| validator | Input Validation |

### How to Run
```bash
git clone https://github.com/sufianmehmoodsoomro/cybersecurity-task.git
cd cybersecurity-task
npm install
node index.js
```
Open browser: http://localhost:3000
